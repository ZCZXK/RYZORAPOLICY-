Privacy Policy

1. Information We Store

RYZORA may store Discord User IDs, Server IDs, Channel IDs, Role IDs, moderation logs, and configuration settings for bot functionality.

2. Purpose of Data

Stored data is used only to provide commands, moderation systems, server configurations, premium systems, and bot features.

3. Private Messages

RYZORA does not intentionally store private direct messages unless required for a specific feature explicitly enabled by users.

4. Security

Reasonable measures are used to protect stored information, but complete security cannot be guaranteed.

5. Third Parties

We do not sell user data to third parties. Some services may rely on external hosting providers or APIs.

6. Data Removal

Users or server owners may request data deletion where applicable.

7. Updates

This Privacy Policy may be updated at any time without notice.
